# 数据集说明

对应大纲第 3 周第 1 项。2026-08-31。

## 大纲点名的三个，实际情况

| 数据集 | 实际情况 |
|---|---|
| ScreenAgent | HuggingFace 上没有，GitHub 仓库页面也没给下载链接，README 只说明了目录结构。需要联系作者或从论文附加材料找。 |
| WebArena | 不是数据集，是一套 docker 部署的网站环境加任务定义，用于在线评测。HF 上的同名条目都是第三方衍生物。 |
| Mind2Web | `osunlp/Mind2Web` 6.4 GB，是 HTML DOM 数据不含截图；带截图的 `osunlp/Multimodal-Mind2Web` 12.9 GB。两者都是 Web 域。 |

三个都不能直接拿来做桌面 grounding 的训练数据。

## 实际使用的

第 3 周微调要证明模型的 UI 元素定位能力有提升，需要两样东西：桌面场景的（截图，指令）→ 坐标训练数据，以及一个能给出数字的评测基准。

| 数据集 | 大小 | 用途 |
|---|---|---|
| `rootsautomation/ScreenSpot` | 574 MB | GUI grounding 的通用评测基准，含 desktop / web / mobile 三个分片，取 desktop 部分作为定位精度的评测集 |
| `showlab/ShowUI-desktop` | 493 MB | 桌面 grounding 训练数据 |

合计约 1 GB，都是 parquet，`datasets` 直接可读。

Mind2Web 不是不能用，它的多模态版本可以作为通用任务规划能力的补充语料，但 13 GB 的下载量和 Web 域的偏差放在 4 周的排期里不划算，暂缓。ScreenAgent 继续找下载渠道，找到了再补进来——它是唯一一个原生桌面域且带完整操作轨迹的，对第 4 周的端到端任务最有参考价值。

## 转换目标

统一转成 `gui_agent/schema.py` 里的格式：截图存盘，指令和目标框转成 `Element`（坐标归一化到 0~1），可执行的动作转成 `Action`。这样同一套结构在微调和评测里都能直接用。
