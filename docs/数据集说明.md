# 数据集说明

对应大纲第 3 周第 1 项。2026-08-31。

## 大纲点名的三个，实际情况

| 数据集 | 实际情况 |
|---|---|
| ScreenAgent | 数据直接放在 GitHub 仓库里，`git clone` 即可，仓库 270 MB。`data/ScreenAgent/train/` 下 203 个 session，另有 `test.zip` 48 MB。内容是操作轨迹：每个 session 一组截图加标注 JSON，含 planning / acting / reflecting 三类响应。HuggingFace 上只有模型权重 `niurl/ScreenAgent`，没有数据集条目。 |
| WebArena | 不是数据集，是一套 docker 部署的网站环境加任务定义。仓库里的 `config_files/test.raw.json` 是 812 条任务规格，要跑必须先把几个网站架起来，里面没有截图。 |
| Mind2Web | `osunlp/Mind2Web` 6.74 GB，是 HTML DOM 数据不含截图；带截图的 `osunlp/Multimodal-Mind2Web` 13.6 GB。两者都是 Web 域。 |

三个都不是（截图，指令）→ 框这种形式的桌面定位标注：WebArena 和 Mind2Web 是 Web 域，ScreenAgent 虽然是原生桌面域，但存的是操作轨迹。

## 实际使用的

第 3 周微调要证明模型的 UI 元素定位能力有提升，需要两样东西：桌面场景的（截图，指令）→ 坐标训练数据，以及一个能给出数字的评测基准。

| 数据集 | 大小 | 用途 |
|---|---|---|
| `rootsautomation/ScreenSpot` | 602 MB | GUI grounding 的通用评测基准，只有一个 test split 共 1272 条，覆盖 iOS / Android / macOS / Windows / Web；按 `data_source` 取 windows 和 macos 两类共 334 条作为定位精度的评测集 |
| `showlab/ShowUI-desktop` | 517 MB | 桌面 grounding 训练数据，train split 共 7496 条，按 9:1 划成 6747 / 749 |

合计约 1.1 GB，都是 parquet，`datasets` 直接可读。

ScreenAgent 的轨迹数据下周并进来。它是三个里唯一原生桌面域的，而且轨迹里含键盘操作，正对上端到端测试查出的短板（模型只会点击）。这周先不用，是因为要先建定位的评测集和训练集，轨迹数据不是这个形式。

Mind2Web 的多模态版本可以作为通用任务规划能力的补充语料，但 13.6 GB 的下载量和 Web 域的偏差放在 4 周的排期里不划算，暂缓。

## 转换目标

统一转成 `gui_agent/schema.py` 里的格式：截图存盘，指令和目标框转成 `Element`（坐标归一化到 0~1），可执行的动作转成 `Action`。这样同一套结构在微调和评测里都能直接用。
