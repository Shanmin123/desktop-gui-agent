# 开发环境配置文档

对应大纲第 1 周第 4 项。

## 硬件与系统

| 项 | 值 |
|---|---|
| 系统 | Windows 11 |
| GPU | NVIDIA GeForce RTX 4080 Laptop，12 GB 显存 |
| 屏幕 | 3840×2160 |

## Python 环境

Anaconda base，Python 3.10.9，torch 2.6.0+cu124 已随环境安装。

## 安装

```bash
pip install -r requirements.txt
python scripts/check_env.py          # 快速检查
python scripts/check_env.py --ocr    # 额外实测 OCR，首次会下载模型权重
```

## 环境检查

`python scripts/check_env.py --ocr`，20 项，通过 19 项。

| 项 | 结果 |
|---|---|
| Python | 3.10.9 |
| PyTorch | 2.6.0+cu124，CUDA 可用 |
| mss 截图 | 3840×2160 |
| pyautogui | 报告屏幕尺寸 3840×2160 |
| 运行分辨率 | 高于推荐值，需改为 1280×720 |
| 其余库 | pynput、OpenCV 4.10、transformers 5.3.0、peft、accelerate、bitsandbytes、datasets、langchain、matplotlib、easyocr、paddleocr 均正常 |

截图端与控制端报告的屏幕尺寸一致，坐标不需要额外换算。

## 运行分辨率

按 Claude Computer Use 文档的推荐设为 1280×720。该分辨率下截图 0.92 MP、长边 1280，在模型输入限制内，截图可以原样送模型，不需要缩放。

## 感知各环节耗时

`python scripts/bench_perception.py`，在本机原生 3840×2160 下实测，模型加载不计入。

| 环节 | 耗时 | 识别到的文字 |
|---|---|---|
| 截图 | 60–110 ms | — |
| 缩放到 1430×804 | 3 ms | — |
| OCR 原图 | 2.43 s | 65 处 |
| OCR 缩放图 | 1.55 s | 22 处 |

缩放能省约 0.9 秒，但识别到的文字少三分之二。在 1280×720 下不需要缩放，这两项开销也会随像素量下降。

大纲第 6 周第 3 项「优化屏幕感知模块」可以从只对发生变化的区域重跑 OCR 入手。
