## 安装

```bash
pip install -r requirements.txt
python scripts/check_env.py          # 快速检查
python scripts/check_env.py --ocr    # 额外实测 OCR，首次会下载模型权重
```

## 感知各环节耗时

`python scripts/bench_perception.py`，3840×2160 全屏，模型加载不计入。

| 环节 | 耗时 | 识别到的文字 |
|---|---|---|
| 截图 | 60–110 ms | — |
| 缩放到 1430×804 | 3 ms | — |
| OCR 原图 | 2.43 s | 65 处 |
| OCR 缩放图 | 1.55 s | 22 处 |

缩放能省约 0.9 秒，但识别到的文字少三分之二，因此 OCR 跑原图，缩放只用于满足模型的输入尺寸限制。

截图是目前最大的固定开销。大纲第 6 周第 3 项「优化屏幕感知模块」可以从只对发生变化的区域重跑 OCR 入手。
