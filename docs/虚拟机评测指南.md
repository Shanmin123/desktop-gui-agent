# 虚拟机评测指南

live 实验（25 个任务评测集、故障注入、复杂任务、不同分辨率）放在 VirtualBox 的 Windows 11
虚拟机里跑。智能体的鼠标键盘动作只落在虚拟机桌面上，宿主机照常使用；每批实验前恢复快照，
起始状态一致。

第 4 周这一轮没有用这套：装虚拟机要重启开启 Windows 虚拟机监控程序平台、下 6 GB 镜像、装系统，
时间都花在准备上，所以直接在本机跑（步骤见 `docs/项目构建说明.md` 第七节）。要无人值守跑长实验、
或者要每批都从完全一样的初始状态开始，再按这份指南装虚拟机。

分工：模型在宿主机显卡上（`scripts/serve_vlm.py`），虚拟机里只跑执行循环和任务验收
（`scripts/vm/guest_worker.py` 从共享目录领任务），宿主机用 `scripts/vm/host_jobs.py`
投任务、收结果。整个过程不需要在宿主机上保存虚拟机的账号密码。

---

## 一、宿主机准备（一次性）

1. **打开 Windows 虚拟机监控程序平台。** 「启用或关闭 Windows 功能」里勾选
   「Windows 虚拟机监控程序平台」，确定后重启。系统的内核隔离已经在用虚拟化，VirtualBox
   要通过这个接口运行。
2. **安装 VirtualBox 7。** 从 virtualbox.org 下载 Windows hosts 安装包，按默认选项安装。
3. **下载 Windows 11 镜像。** 微软官网「下载 Windows 11」页面的「下载 Windows 11 磁盘映像
   (ISO)」，约 6 GB。

## 二、创建虚拟机

在 VirtualBox 里新建：

| 项 | 值 |
|---|---|
| 名称 | `agent-win11`（`host_jobs.py` 默认用这个名字，改了就在命令里传 `--vm`） |
| 镜像 | 上一步的 ISO |
| 内存 / CPU | 8 GB / 4 核 |
| 磁盘 | 64 GB |
| 显存 | 128 MB（1920×1080 那批要用） |
| 网络 | NAT（默认）。虚拟机里访问 `10.0.2.2` 就是宿主机 |
| 共享文件夹 | 名称 `vm_exchange`，宿主机路径 `desktop-gui-agent\logs\vm_exchange`（先建好这个空文件夹），勾选自动挂载，挂载点 `Z:`，不要勾只读 |
| 共享剪贴板 / 拖放 | 关闭 |

只共享交换目录，不共享整个项目：智能体在虚拟机里能看到共享文件夹。

## 三、虚拟机里的准备（一次性）

1. 装 Windows，建本地账户。装完在 VirtualBox 菜单「设备 → 安装增强功能」，运行光盘里的
   安装程序后重启（共享文件夹和分辨率调整要靠它）。
2. 装 Python 3.10（python.org，勾选 Add python.exe to PATH）。
3. 把代码仓库拷到 `C:\agent\desktop-gui-agent`（从 GitHub 克隆，或宿主机打包后临时放进
   `Z:` 再拷出来），然后在仓库目录里：

   ```
   pip install -r scripts\vm\requirements-guest.txt
   ```

4. 设 worker 开机自启：`Win + R` 输入 `shell:startup`，在打开的文件夹里新建快捷方式，目标填

   ```
   python C:\agent\desktop-gui-agent\scripts\vm\guest_worker.py --exchange Z:\ --repo C:\agent\desktop-gui-agent
   ```

5. 设自动登录（恢复快照后能直接进桌面、worker 自己起来）：`Win + R` 输入 `netplwiz`，取消
   「要使用本计算机，用户必须输入用户名和密码」。选项不出现时，先在「设置 → 账户 → 登录选项」
   里关掉「为了提高安全性，仅允许使用 Windows Hello 登录」。
6. 连通性检查：宿主机先起模型服务（见下一节第 1 条），虚拟机里运行

   ```
   python -c "import urllib.request; print(urllib.request.urlopen('http://10.0.2.2:8000/v1/models').read())"
   ```

   打印出模型名就通了。
7. 关机，在 VirtualBox 里拍快照，命名 `clean`。

## 四、宿主机上跑实验

1. 单独起模型服务（手动调试时用；`host_jobs.py` 会自己起停）：

   ```
   python scripts/serve_vlm.py --model Qwen/Qwen3.5-4B --adapter checkpoints/q35_2sp
   ```

2. 计划跑的几批一条命令跑完。每批会起对应的模型服务、恢复快照并开机、等 worker 心跳、投任务、
   等回执、把日志拷回 `logs/`；显卡队列从第一批暂停到最后一批：

   ```
   python scripts/vm/run_batches.py --list     # 先看要跑哪几批、每批的完整命令
   python scripts/vm/run_batches.py            # 全部按顺序跑
   python scripts/vm/run_batches.py --only q35_2sp_suite,q35_base_suite
   ```

   | 批次 | 内容 | 模型服务 | 日志 |
   |---|---|---|---|
   | `q35_2sp_suite` | 25 个任务 × 3 次 | Qwen3.5-4B + `q35_2sp` | `tasks_vm_q35_2sp_suite.json` |
   | `q35_base_suite` | 25 个任务 × 3 次（微调前后对比） | Qwen3.5-4B | `tasks_vm_q35_base_suite.json` |
   | `q35_robust_noretry` | 基础 5 个 × 3 次，30% 故障注入，关重试 | Qwen3.5-4B + `q35_2sp` | `tasks_vm_q35_robust_noretry.json` |
   | `q35_robust_retry` | 同上，开重试（额度 2） | 同上 | `tasks_vm_q35_robust_retry.json` |
   | `q35_2sp_complex_plan` | 复杂 4 个 × 3 次，先拆解再执行 | 同上 | `tasks_vm_q35_2sp_plan_complex.json` |
   | `q35_2sp_suite_1080p` | 25 个任务 × 1 次，1920×1080 | 同上 | `tasks_vm_q35_2sp_1080p_suite.json` |
   | `q25_2sp_suite` | 25 个任务 × 3 次（对照，坐标口径 pixel） | Qwen2.5-VL-3B + `lora_2sp` | `tasks_vm_q25_2sp_suite.json` |

   按第 3 周基础任务平均每次 94 s 估算，一批评测集（75 次）约 2 小时，7 批全部跑完约 8 小时。
   除分辨率那批外都在 1280×720 下跑。

3. 只跑一批、或者换参数时直接用 `host_jobs.py`，`--` 后面是交给虚拟机里 run_tasks.py 的参数：

   ```
   python scripts/vm/host_jobs.py --vm agent-win11 --snapshot clean \
       --serve-model Qwen/Qwen3.5-4B --serve-adapter checkpoints/q35_2sp --id q35_2sp_suite -- \
       --live --set suite --repeat 3 --resolution 1280x720 --model Qwen/Qwen3.5-4B \
       --api-base http://10.0.2.2:8000/v1 --api-key local --api-coord-space rel1000 \
       --tag vm_q35_2sp
   ```

4. 跑完出表出图：

   ```
   python scripts/summarize_suite.py      # 成功率（95% 区间）、平均执行时间、错误率，按难度档和任务拆开
   python scripts/make_charts.py          # suite_by_level.png 用评测集的日志
   ```

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 一直停在等显卡 | 宿主机上的训练或评测还在跑，会等这一步结束（最长 12 小时）；急用就先停掉消融队列 |
| `15 分钟没等到 worker 心跳` | 快照里没设自动登录，或开机自启的快捷方式路径不对；在 VirtualBox 窗口里看一下桌面 |
| 虚拟机访问 `10.0.2.2:8000` 超时 | 宿主机上 `serve_vlm.py` 没起来，看 `logs/_serve_vlm_8000.txt` |
| `Z:` 不存在 | 增强功能没装，或共享文件夹没勾自动挂载 |
| 截图是黑的 | 虚拟机窗口最小化不影响截图；黑屏多半是显示器进入了睡眠，在电源设置里把「关闭屏幕」设为「从不」后重新拍快照 |
