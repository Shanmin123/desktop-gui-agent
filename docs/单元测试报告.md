# 单元测试报告

对应大纲第 2、4 周交付物，第 5~7 周新增的模块同步补测。

运行 `pytest tests/ -q`，共 693 项，默认执行的 692 项全部通过。余下 1 项会真的切换屏幕分辨率，默认跳过，`GUI_AGENT_DISPLAY_TESTS=1` 时运行。

测试用例分两层。

**一、基础测试（功能单一）。** 每个模块单独验证：输出 JSON 的解析、元素编号到坐标的换算、
单个动作的执行与参数校验、按键名归一化、指标计算、数据构建。下表按模块列出。

**二、长链路测试（模拟真实用户从头走到尾）。** 一个真实任务要连着做十几步，中间还会因为
「当前子任务推不动」而重新拆解，这类问题在单功能测试里看不出来。另有两条用例把整条执行循环跑长：

- 16 步走完 4 个子任务、中间两次重新拆解，验证子任务按顺序推进、重拆替换掉剩下的计划、
  历史一路带着、重拆本身不占步数预算；
- 15 步不开拆解，验证历史累积正确，且动作各不相同时不会被「连续重复同一动作」的卡住检测误判终止。

真实桌面上的长链路由 25 个任务的评测集承担：T1 一两步完成（对应第一层），T2 在单个程序里多步
（打开、编辑、保存），T3 跨程序（用计算器算完写进文件、从网页取值写进文件）。
